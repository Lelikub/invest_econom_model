# AeroCarbon Synth — план реализации

**Спецификация:** `../../task/Promt.md`, PDF задания и лекция 5.
**Цель:** единая команда PDF → CSV → типизированные входы → расчёты → независимый Excel → тесты → PNG/DOCX/ZIP.
**Архитектура:** ApplicationInterface → PipelineController → сервисы → пассивные dataclass-модели. Формулы изолированы в калькуляторах. Работа выполняется в текущем каталоге, только в `3/app`, без субагентов и изменений удалённого репозитория.

## Общие ограничения

- Данные задания имеют приоритет над лекцией; противоречия раскрываются.
- CSV котировок копируется побайтно; полные месяцы — последняя наблюдаемая торговая дата, последний неполный месяц исключается.
- Нет выдуманных налоговых платежей/DSRA/дефолтного спреда. Отсутствие Excel-пересчёта означает NOT_VERIFIED.
- Формулы Excel независимы от Python-калькуляторов; допуск rtol=1e-8, atol=1e-10.
- Все тесты запускаются контроллером; критическая ошибка даёт FAILED и сохраняет диагностику.

## Задачи и интерфейсы

1. **Извлечение и данные:** `PdfExtractionService.extract(pdf, data_dir)` создаёт CSV с происхождением; `DataRepository.load(data_dir)` возвращает ProjectInputData, MarketAssumptions, ShockParameters. Сначала тесты единиц, полноты и реального PDF; затем реализация и pytest.
2. **Математика:** отдельные Tax/Hamada/CAPM/WACC/OLS/Stress/DSCR/Credit/Waterfall/Discount калькуляторы принимают числа или DTO, возвращают DTO. Сначала независимые контрольные примеры и граничные тесты; затем реализация.
3. **Верификация и визуализация:** ExcelGroundTruthWriter принимает входы и результаты, строит формулы, ExcelService пересчитывает отдельным процессом; ComparisonService читает кэш. ChartWriter строит графики из экспортируемых таблиц, ChartValidationService проверяет границы/числа. Тесты недоступного движка, ковенантных порогов, графического баланса.
4. **Оркестрация и отчётность:** PipelineController запускает весь процесс, тесты и проверки артефактов; ReportingService формирует русский DOCX, HarnessWriter — наблюдавшиеся события. Интеграционный тест целостности DOCX/XLSX/ZIP и контролируемого отказа.

## Review Focus

Изменённый PDF не должен использовать устаревшие CSV; повреждённые цены должны отклоняться; DSCR<1 без коэффициентов не должен давать число; остатки предыдущего запуска не должны подтверждать новый; сбой Excel не должен оставлять процесс или статус PASS.
