# AeroCarbon Synth — практическая работа 3

Python 3.14. Установить зависимости: `python -m pip install -r 3/app/requirements.txt`.
В этом рабочем каталоге подготовлено локальное окружение `3/app/.venv`.

Одна команда из корня репозитория (PowerShell):

```powershell
& '3/app/.venv/Scripts/python.exe' '3/app/main.py'
```

Или с установленными зависимостями: `python 3/app/main.py`.
Запуск из любого cwd поддерживается, пути по умолчанию вычисляются от приложения.

Явные входы:

```powershell
python 3/app/main.py --pdf '3/data/Задание_к_практическому_занятию_3_ФИП.pdf' --prices '3/data/hxl_gspc_adj_close_5y.csv' --lecture 'lectuion/Лекция 5 ФИП слайды.pdf'
```

Все тесты, PDF-парсинг, повторное чтение CSV, расчёты, Excel COM, графики, DOCX и ZIP выполняются автоматически. `--output` допустим только внутри каталога приложения. `--excel-timeout` задаёт ограничение времени отдельного процесса Excel.

Excel COM требует установленный Microsoft Excel и доступ к интерактивному сеансу Windows. В ограниченной песочнице COM может быть недоступен: тогда формулы сохраняются, но сверка получает NOT_VERIFIED. `openpyxl` не пересчитывает формулы. На других ОС формулы сохраняются без подтверждённого пересчёта.

Статусы и коды возврата:

- `COMPLETED_WITH_LIMITATIONS` (0): реализованные расчёты, Excel, тесты и графики проверены; отсутствующие входы исходного задания раскрыты.
- `NOT_VERIFIED` (2): нет подтверждённого Excel-пересчёта или hash-bound записи отдельного визуального просмотра.
- `FAILED` (1): критическая ошибка; сохранены `run_manifest.json`, Harness Log и traceback.

`SUCCESS` не используется при ограничениях исходников. Полный фактический waterfall не определён без cash taxes/NWC/DSRA; отчёт содержит отдельно подписанную иллюстрацию и буквальную демонстрацию противоречивого PDF. Ниже DSCR=1 неизвестные дефолтные коэффициенты вызывают контролируемый отказ. Альфа Дженсена, NPV/IRR и типовая доходность отрасли не выдумываются.

Месячный ряд: последняя наблюдаемая цена месяца. Последний неполный месяц исключается по последнему буднему дню; биржевые праздники отдельно не подтверждены. Начальный месяц даёт начальную цену; 60 цен означают 59 доходностей. Исходный CSV сохраняется побайтно, экстремумы не удаляются. Основной WACC использует beta=1.25 из PDF, OLS beta — диагностика.

Результаты: `output/Ground_Truth.xlsx`, `output/HARNESS_LOG.xlsx`, `output/Итоговый_отчет_ФИП_Практическая_3.docx`, `output/Практическая_3_ФИП_результаты.zip`, `output/tables`, `output/charts`. Архив содержит код, тесты, входные копии, журналы и документацию; виртуальное окружение исключено. Для запуска распакованного архива используйте входные копии `data/source_assignment.pdf`, `data/hxl_gspc_adj_close_5y.csv`, `data/source_lecture5.pdf` через CLI.

История наблюдений сохраняется append-only в `logs/events.jsonl`; прежние основные артефакты — `logs/prior_outputs/<run_id>`. Архивы предыдущих запусков не вкладываются в новый ZIP. Визуальная проверка хранится в `docs/visual_review.json` с SHA256; при изменении изображения статус сбрасывается автоматически. Автоматический графический аудит не выдаётся за отдельный просмотр.

Документация: [формулы](docs/formula_registry.md), [трассируемость](docs/requirements_traceability.md), [ограничения](docs/SOURCE_ISSUES.md), [план](docs/implementation_plan.md).

Для разработки: `python -m pytest 3/app/tests -q`. Внешний отдельный запуск тестов не требуется для выполнения задания.
