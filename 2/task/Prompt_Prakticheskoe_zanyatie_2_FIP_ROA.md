# 10. CRR — СЛУЖЕБНЫЕ ПАРАМЕТРЫ

Использовать формулы из задания.

### Шаг:

```text
dt = T / N
```

### Up factor:

```text
u = exp(sigma * sqrt(dt))
```

### Down factor:

```text
d = 1 / u
```

### Risk-neutral probability:

```text
p = (
    exp((r - delta) * dt) - d
) / (u - d)
```

### Discount factor:

```text
discount_factor = exp(-r * dt)
```

### Проверка рекомбинации:

```text
u * d ≈ 1
```

---

# 11. БЕЗАРБИТРАЖНОЕ УСЛОВИЕ

Программно проверить:

```text
d < exp((r - delta) * dt) < u
```

```text
0 < p < 1
```

При нарушении:

# 13. ПРЯМОЙ ХОД — S-LATTICE

Построить рекомбинирующую решетку:

```text
S[i,j] = S0 * u^j * d^(i-j)
```

где:

```text
0 <= i <= N
0 <= j <= i
```

Не хардкодить `N = 3`.

Модель должна поддерживать произвольное допустимое число шагов.

Проверить:

- `S[0,0] == S0`;
- количество узлов;
- `S > 0`;
- рекомбинацию;
- отсутствие `NaN`;
- отсутствие `Inf`.

---

# 14. ОБРАТНАЯ ИНДУКЦИЯ — C-LATTICE

Терминальный payoff:

```text
C[N,j] = max(S[N,j] - K, 0)
```

На промежуточном шаге:

```text
IntrinsicValue =
    max(S[i,j] - K, 0)
```

```text
ContinuationValue =
    exp(-r * dt) *
    (
        p * C[i+1,j+1]
        +
        (1-p) * C[i+1,j]
    )
```

```text
C[i,j] =
    max(
        IntrinsicValue,
        ContinuationValue
    )
```

Также:

```text
exercise_now =
    IntrinsicValue > ContinuationValue
```

Для каждого узла сохранить:

- `i`;
- `j`;
- `S`;
- `IntrinsicValue`;
- `ContinuationValue`;
- `C`;
- `Decision = WAIT / EXERCISE`.

# 30. BANKABILITY И DSCR

Объяснить, почему банк не принимает ROV как полноценное обеспечение.

Разграничить:

```text
Option Value
```

и:

```text
Debt Service Cash Flow
```

ROV:

- модельно зависит от sigma;
- зависит от решений менеджмента;
- не обязательно является денежным потоком;
- не гарантирует выплаты по долгу.

Показать:

```text
DSCR =
Cash Flow Available for Debt Service
/
Debt Service
```

и критерий из задания:

```text
DSCR >= 1.30x
```

Если данных для расчёта DSCR нет — не выдумывать их.

В отчёте написать:

**«Численный DSCR не рассчитывается вследствие отсутствия необходимых параметров обслуживания долга».**
