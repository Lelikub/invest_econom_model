# Практическая работа № 2 ФИП — ROA / CRR

Приложение извлекает входные параметры из PDF, создаёт CSV, рассчитывает американский опцион на расширение методом CRR, строит формульную Excel Ground Truth, запускает тесты и стресс-сценарии, формирует графики, Harness Log, Markdown и Word-отчёт на основе приложенного шаблона.

## Требования

- Python 3.10 или новее;
- `pdftotext` из Poppler или Xpdf (в Windows также поддерживается путь Git for Windows);
- Microsoft Excel на Windows для **фактического** пересчёта и численной сверки Excel; если он недоступен, книга формул создаётся, но сверка получает статус `NOT_VERIFIED`;
- библиотеки из `requirements.txt`.

```powershell
python -m pip install -r 2/app/requirements.txt
python 2/app/main.py
python -m unittest discover -s 2/app/tests -v
```

В данном рабочем окружении исполняемый Python находится в `C:\Program Files\PostgreSQL\15\pgAdmin 4\python\python.exe`; ранее установленные библиотеки в `1/app/.python-packages` подключаются автоматически, если этот каталог есть.

## Данные и принципы

`2/data/Задание_к_практическому_занятию_2_ФИП.pdf` — первичный источник. Исходные числа находятся на стр. 5. `m=1` означает, что дополнительные потоки второй очереди эквивалентны базовым; в формуле решётки используется `S0*m` (при текущем задании это `S0`). Стресс `σ=0.0001` при данных `r−δ=0.01` может нарушать безарбитражное окно; приложение записывает диагностический статус и не выдаёт ложную стоимость опциона. `p=1` применяется только как искусственный тест логики обратной индукции.

Excel Ground Truth содержит самостоятельные формулы для всех параметров и узлов базового сценария. Числовая сверка читает только кэш значений, записанный самим Microsoft Excel; при недоступности COM значения не подменяются расчётом Python.

## Выходные файлы

- `data/source_data.csv` — входные данные и происхождение;
- `output/Ground_Truth_ROA.xlsx` — формульная модель;
- `output/excel_python_reconciliation.csv` — сравнение каждого параметра и узла;
- `output/scenario_comparison.csv`, `output/sensitivity.csv` — сценарий и аудит σ;
- `output/crr_tree_base.png`, `output/crr_tree_sigma_70.png` — деревья;
- `output/HARNESS_LOG.xlsx`, `logs/pipeline.log`, `logs/test_results.txt` — журналы;
- `output/FINAL_REPORT.md`, `output/Итоговый_отчет_Практическая_работа_2_ФИП.docx` — отчёты.
