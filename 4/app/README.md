# Практическая работа № 4 ФИП

Итоговый Word-отчет формируется на основе пользовательского шаблона `lectuion/Шаблон_отчета_ЭА_краткий_v2 (3).docx`. Сохраняются титульный блок и параметры страницы; содержание распределяется по главам1–12 шаблона. Инструкции из главы13 применяются к оформлению и удаляются из сдаваемого отчета. Основной текст — Times New Roman12, заголовки —15/13pt, формулы — Cambria Math12, таблицы — Table Grid с синими шапками. Полные таблицы остаются в приложениях; все13 графиков связаны с таблицами и анализом. ФИО/группа/курс/город оставлены незаполненными, поскольку не предоставлены.

Контрольная копия шаблона — `data/report_template.docx`; SHA256 и происхождение — в `run_manifest.json → sources.report_template`, аудит глав/стилей/заполнителей — `output/report_structure.json`. Для выбора обновленного шаблона используйте `--template 'lectuion/Шаблон_отчета_ЭА_краткий_v2 (3).docx'`. Поврежденный или отсутствующий шаблон вызывает контролируемый отказ вместо возврата к прежнему оформлению. При доступности Microsoft Word pipeline дополнительно создает `output/internal_review/report.pdf` для проверки верстки, не меняя исходный DOCX.

Сравнение завода PFSA/PEM в Германии, Сербии и Вьетнаме. Все новые файлы находятся в `4/app`; работы 1–3 не изменяются.

Одна команда из корня репозитория:

```powershell
python 4/app/main.py
```

Подготовленное локальное окружение (обходит неработающий системный WindowsApps alias `python`):

```powershell
& '4/app/.venv/Scripts/python.exe' '4/app/main.py'
```

Для нового окружения: Python 3.11+ и `python -m pip install -r 4/app/requirements.txt`. Зафиксированы фактически использованные версии; если конкретная версия не поддерживает выбранный Python, используйте Python 3.14 либо совместимые версии библиотек с последующим полным запуском тестов. `.venv` не включается в архив. В текущей среде зависимости скопированы из уже установленных дистрибутивов, исходники прежних работ не копировались.

Пути по умолчанию вычисляются от main.py и не зависят от cwd. Приоритет источников: явные `--pdf`/`--lecture` → `data/source_assignment.pdf` и `data/source_lecture7.pdf` → `4/data/` и `lectuion/`. Контрольные копии PDF и SHA256 сохраняются в `data/`. Поддерживаются `--excel-timeout 90` и явный `--output`, равный `4/app/output`; другие каталоги выхода отклоняются для сохранения целостности общего pipeline.

Интерфейс → контроллер → сервисы → frozen dataclass / чистые калькуляторы. PDF извлекается через PyMuPDF (геометрические таблицы и regex текстового слоя), производственные параметры экспортируются в восемь CSV с provenance и повторно читаются. Формулы не находятся в DTO/контроллере. `CrossBorderSupplyChainEvaluator` объединяет специализированные калькуляторы риска, CAPEX, логистики, налогов, амортизации, CF и метрик. `ScenarioService` использует replace и сохраняет базовые входы.

Контроллер последовательно исполняет 00–15. Сначала независимый Excel базы; после расчета сценариев та же книга расширяется всеми сценариями/edge cases и снова пересчитывается. Excel пересчитывается настоящим Microsoft Excel через изолированный COM worker, а не openpyxl. На Windows требуется доступ к сеансу Office: в ограниченной песочнице COM может возвращать «Указанный сеанс работы не существует». Запуск из обычной пользовательской PowerShell-сессии дает доступ к установленному Excel. Без такого доступа книга с формулами сохраняется, сверка получает NOT_VERIFIED. Числа Python в кэш не вставляются.

Правила: Parent NPV основной критерий; calendar t0…13; VNM полугодия t3/t13; NWC фиксирован, без WHT; распределяется 100% положительного операционного CF; cash tax≥0 без придуманного refund; TV=0. В `parent_cashflow_literal_pdf` точно сохранена типографика стр.13 `FCFF−ΔNWC*(1−WHT)` при FCFF≤0. Эта конфликтная запись не участвует в инвестиционном вердикте. Все налоговые ставки — условия учебного PDF, а не заявление о действующем законодательстве.

Результаты:

- `output/Ground_Truth.xlsx` — независимые формулы всей цепочки, всех сценариев и edge cases.
- `output/reconciliation.csv` — построчная Python/Excel-сверка с допусками, единицами и formula_id.
- `output/Итоговый_отчет_ФИП_Практическая_4.docx` — таблица → график → анализ, встроенные рисунки.
- `output/FINAL_REPORT.md`, `results_summary.json`, `report_sections.json` — те же расчетные DTO.
- `output/HARNESS_LOG.xlsx` / CSV, `logs/events.jsonl` — реальные дефекты отдельно от проблем источника.
- `output/tables/`, `output/charts/` — исходы графиков, годовые CF, стресс-изменения, сценарная статистика.
- `output/Практическая_4_ФИП_результаты.zip` — исходники, тесты, исходные PDF/CSV, документы и результаты; проверяются CRC и SHA256 каждого вложенного файла.
- `output/run_manifest.json`, `package_manifest.json` — стадии, версии, источники и контрольные суммы. Хеш ZIP записывается снаружи архива, чтобы избежать циклического хеширования.

50+ unit/integration/edge тестов автоматически запускаются из pipeline. Для разработки:

```powershell
& '4/app/.venv/Scripts/python.exe' -m pytest 4/app/tests -q --basetemp=4/app/logs/test_tmp_manual -p no:cacheprovider
```

Коды возврата: 0 — `SUCCESS` либо `COMPLETED_WITH_LIMITATIONS`; 2 — `NOT_VERIFIED` (нет Excel или реального визуального аудита); 1 — `FAILED`. Противоречия источника раскрыты в `docs/SOURCE_ISSUES.md`; при подтвержденных вычислениях и этих ограничениях используется `COMPLETED_WITH_LIMITATIONS`. Старые основные артефакты сохраняются в `logs/prior_outputs/<run_id>/`, а manifest текущего запуска всегда отражает текущую попытку.

Визуальная проверка — реальный просмотр всех PNG с записью filename, SHA256, reviewer, review_time, status в `docs/visual_review.json`. Код не выдумывает просмотр; проверяет соответствие ранее записанных SHA256. При изменении графика статус сбрасывается в VISUAL_NOT_VERIFIED. Численная проверка, размер/целостность PNG и пределы осей выполняются автоматически. IQR-диагностика сохраняет все стрессовые и необычные значения без фильтрации.

Документация: `docs/formula_registry.md`, `requirements_traceability.md`, `assumptions_and_decisions.md`, `implementation_plan.md`, `development_observations.json`. Формулы, не найденные в лекции как отдельные определения, так и помечены; номера слайдов не выдумываются.
