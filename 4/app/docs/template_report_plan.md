# Отчет по шаблону ЭА v2 — Implementation Plan

> Исполнение: последовательно в текущем `4/app`, без субагентов.

**Goal:** единый pipeline формирует окончательный DOCX на основе предоставленного шаблона, сохраняя подтвержденные расчеты и аналитическую связность.

**Architecture:** неизменяемые расчетные DTO → сервис распределения содержания по главам шаблона → WordReportWriter на базе `Document(template)` → проверка структуры/стилей → общий аудит/ZIP. Контрольная копия шаблона и SHA256 включаются во входы pipeline и архив.

**Tech Stack:** существующие Python/python-docx/pytest; дополнительных зависимостей нет.

**Spec:** `lectuion/Шаблон_отчета_ЭА_краткий_v2 (3).docx`, SHA256 `cf8b89262c58256410a4d8f80fc3b6a5a47e2166413eb183cea41e67a30189e7`.

## Решения

- Использовать исходный DOCX как основу, сохраняя титульный блок и параметры A4/полей. Создание похожего документа с нуля не обеспечивает наследование шаблона.
- Применить разделы 1–12, включая самостоятельный Harness Log, тесты, Data Quality Report и итоговые выводы. Раздел 13 — инструкция к заполнению, а не содержание отчета.
- На титуле заполнить номер/название/объект/год. Дисциплина соответствует источнику задания ФИП. ФИО/группа/курс/город не предоставлены и остаются явными незаполненными полями без квадратных скобок.
- Сохранить исходные численные результаты и все 13 графиков. Таблица → график → интерпретация остаются локальными аналитическими блоками в главах 6/8/9/10. Глава 9 включает реальную визуализацию чувствительности и реестр/контроль изображений.
- Основной текст TNR12, интервал1.15, отступ1.25см; заголовки15/13pt #1F4E78; формулы Cambria Math12 по центру с определениями переменных; таблицы Table Grid с синими шапками; изображения/подписи по центру.
- Полные исходы/годовые таблицы сохранить в приложениях. Технические метаданные запуска размещаются в приложении, а не на титуле.
- Для повторного запуска использовать контрольную копию в data/report_template.docx; CLI --template задает явный источник. Отсутствующий/поврежденный шаблон вызывает контролируемый отказ.

## Review Focus

- Нельзя молча вернуться к старому генератору при отсутствии шаблона.
- Нельзя выдумывать персональные данные или оставить служебные заполнители.
- Заголовки/таблицы/рисунки должны помещаться в полезной ширине A4.
- Все расчетные блоки и изображения должны попасть в отчет ровно один раз.
- Манифест и архив должны соответствовать новой контрольной копии шаблона.

- Первый полный запуск по шаблону:61 тест PASS,10365 Excel-сравнений PASS,35 расчетных блоков сохранены; Word16 экспортировал47 страниц.
- Фактический просмотр титула, основного текста и формул обнаружил подмену шрифта темой и двойное PAGE. Исправления закреплены регрессионным тестом (RED→GREEN). Финальный статус повторного полного запуска определяется output/run_manifest.json, главы и стили — output/report_structure.json.
