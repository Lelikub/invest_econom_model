# Практическая работа 4 — Implementation Plan

> Исполнение: superpowers:executing-plans, последовательно, без субагентов.

**Goal:** воспроизводимый расчет Parent NPV для DEU/SRB/VNM из PDF с независимым Excel, тестами и отчетом.

**Architecture:** интерфейс → контроллер → сервисы → неизменяемые DTO / чистые калькуляторы. CSV является единственным источником производственных параметров. Независимый расчет Excel выполняется формулами, кэш считывается только после реального COM-пересчета.

**Tech Stack:** Python 3.11+, PyMuPDF, numpy/scipy/pandas, openpyxl, matplotlib, python-docx, pytest, pywin32 (Windows).

**Spec:** `../../task/Промт_ФИП_Практическая_4_invest_econom_model.md`, PDF задания (15 страниц), лекция 7 (32 слайда).

## Global Constraints

- Все новые файлы только в `4/app/`; предыдущие работы не изменяются.
- Без субагентов; один вызов ApplicationInterface.run(argv).
- Parent NPV основной критерий; TV=0; календарь t=0…13.
- WHT только с положительного операционного потока; NWC и CAPEX отдельно.
- Не подтвержденные Excel/визуальные проверки получают NOT_VERIFIED.
- Изменения остаются локальными, без commit/push и изменения ветки.

## Design and approaches

Выбран вариант, прямо заданный пользователем: модульный Python и формульный Excel. Монолитный скрипт нарушает разделение ответственности; Python-кэш в Excel нарушает независимость проверки. Интерфейс командный, веб-сайт не требуется. Дополнительное согласование проектных решений не вводится: мастер-промт предписывает исполнять определенные части без остановки.

## Review Focus

- Повреждение PDF/CSV, пропуски и единицы: строгий отказ, без значений по умолчанию.
- Отрицательный EBIT: cash tax=0; буквальная формула отдельно.
- Необычные CF: статусы отсутствующего/множественного IRR и DPP.
- Excel без кэша и устаревший визуальный аудит: никогда PASS.
- Повторный запуск и ошибка: текущий manifest и append-only история; старый отчет не маскирует отказ.
